# Send Conditioner

センド（FX チャンネル）の返りを整える VST3 エフェクトです。
**リバーブ／ディレイの「後ろ」のスロットに挿してください。**
プリディレイとフィルターは後ろに挿しても前に挿したのと同じ結果になり、ダッキングとゲートは後ろでないと効かないため、この位置に統一しています。

## 処理の順番

プリディレイ → HPF / LPF → 低域モノ化 → ステレオ幅 → 自動ゲイン → ダッカー × テンポLFO × テール・ゲート → Mix → 出力 → 素通し比較 → モノ確認

## 各セクション

| セクション | 内容 |
|---|---|
| プリディレイ | テンポ同期（1/64〜1/2、付点・3連あり）またはミリ秒。最大 3 秒 |
| フィルター / ステレオ幅 | HPF・LPF（12/24 dB/oct、端でOFF）、指定周波数以下のモノ化、幅 0〜200% |
| ダッカー | サイドチェーン入力（原音）が鳴っている間、返りを下げる |
| テール・ゲート | 判定信号がしきい値を下回ってから、ホールド長（1/8〜2小節）の後に残響を切る |
| テンポLFO | ホストの再生位置に同期して返りを周期的に下げる（Pump / Sine / Ramp） |
| 出力 | 自動ゲイン、Mix、出力ゲイン、モノ確認、素通し比較、レベル・位相相関メーター |

- **自動ゲイン**が補正するのは、フィルターとステレオ幅で変わった音量だけです。ダッカー・ゲート・LFOでの音量変化は、効果として残します。
- **テール・ゲート**は、サイドチェーンで信号を受信しているときはその信号で判定します。受信していないとき（5秒以上無音のときを含む）は、このプラグインへの入力で判定します。

## Cubase でのサイドチェーン設定

1. プラグイン画面上部のサイドチェーンボタンを ON にする
2. 原音トラック（ボーカルなど）の Sends で、送り先にこのプラグインのサイドチェーンを選ぶ
3. ヘッダーの表示が「サイドチェーン: 受信中」になれば接続できています

## インストール（テスト用）

Actions の成果物 zip を展開し、`install_for_test.bat` を実行してから DAW でプラグインを再スキャンしてください。

## ビルド

```
cmake -B build -A x64
cmake --build build --config Release
```
